## 🎯 Цель работы
Освоить управление ходом выполнения программы с использованием циклических конструкций, научиться вычислять значения сложных выражений (знакопеременных рядов) и анализировать типы данных переменных в процессе выполнения алгоритма.

## 📝 Задание
Необходимо вычислить значение выражения (суммы ряда) при заданных параметрах:
*   **X** — основание степени (независимая переменная).
*   **N** — количество слагаемых ряда.
*   **Z** — результирующая сумма ряда.

Для каждой используемой переменной необходимо вывести её текущее значение и тип данных (`type`).

## 🧮 Математическая модель
Вычисляется частичная сумма ряда по формуле:

$$
Z = \sum_{i=1}^{N} (-1)^{i-1} \cdot \frac{X^{i-1}}{i \cdot (i+1)}
$$

Где:
*   $(-1)^{i-1}$ — обеспечивает чередование знаков слагаемых.
*   $X^{i-1}$ — числитель (степень основания).
*   $i \cdot (i+1)$ — знаменатель (произведение последовательных чисел).
